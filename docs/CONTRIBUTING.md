# 🤝 دليل المساهمة - متجر الأطفال

## مرحباً بك في مشروع متجر الأطفال!

نحن نرحب بمساهماتك في تطوير هذا المشروع. يرجى قراءة هذا الدليل قبل المساهمة.

## 📋 قواعد المساهمة

### 🔒 الأمان أولاً
- **لا تشارك أي معلومات حساسة** مثل كلمات المرور أو مفاتيح API
- **اتبع أفضل الممارسات الأمنية** في جميع التعديلات
- **اختبر التعديلات الأمنية** قبل إرسال Pull Request

### 💻 معايير الكود
- **اتبع PSR-12** لمعايير كتابة PHP
- **استخدم أسماء متغيرات وصفية** باللغة الإنجليزية
- **أضف تعليقات باللغة العربية** للشرح
- **اكتب اختبارات** للميزات الجديدة

### 🌐 اللغة العربية
- **جميع النصوص في الواجهة** يجب أن تكون بالعربية
- **استخدم خط Cairo** للنصوص العربية
- **تأكد من دعم RTL** في التصميم
- **اختبر على المتصفحات المختلفة**

## 🚀 كيفية المساهمة

### 1. إعداد البيئة المحلية

```bash
# استنساخ المشروع
git clone https://github.com/HA1234098765/dunya-alatfaal-shop.git
cd dunya-alatfaal-shop

# تثبيت التبعيات
composer install
npm install

# إعداد البيئة
cp .env.example .env
php artisan key:generate

# إعداد قاعدة البيانات
php artisan migrate
php artisan db:seed

# بناء الأصول
npm run build

# تشغيل الخادم
php artisan serve
```

### 2. إنشاء فرع جديد

```bash
# إنشاء فرع للميزة الجديدة
git checkout -b feature/اسم-الميزة

# أو لإصلاح خطأ
git checkout -b fix/وصف-الإصلاح
```

### 3. تطوير الميزة

- **اكتب كود نظيف ومنظم**
- **أضف اختبارات للميزة الجديدة**
- **تأكد من عمل جميع الاختبارات**
- **اتبع معايير الأمان**

### 4. اختبار التعديلات

```bash
# تشغيل الاختبارات
php artisan test

# فحص الأمان
php artisan security:audit

# تحسين الأداء
php artisan optimize:performance

# فحص معايير الكود
./vendor/bin/phpcs
```

### 5. إرسال Pull Request

```bash
# إضافة التعديلات
git add .

# إنشاء commit مع رسالة وصفية
git commit -m "✨ إضافة ميزة جديدة: وصف الميزة"

# رفع الفرع
git push origin feature/اسم-الميزة
```

## 📝 معايير Commit Messages

استخدم الرموز التالية في بداية رسائل الـ commit:

- `✨` للميزات الجديدة
- `🐛` لإصلاح الأخطاء
- `🔒` للتحسينات الأمنية
- `⚡` لتحسينات الأداء
- `🎨` لتحسينات التصميم
- `📚` للتوثيق
- `🧪` للاختبارات
- `🔧` لتحديث الإعدادات

### أمثلة:
```
✨ إضافة نظام تقييم المنتجات
🐛 إصلاح خطأ في حساب الضرائب
🔒 تحسين أمان نظام الدفع
⚡ تحسين سرعة تحميل الصفحات
```

## 🧪 الاختبارات

### أنواع الاختبارات المطلوبة:

1. **Unit Tests** - اختبار الوحدات الفردية
2. **Feature Tests** - اختبار الميزات الكاملة
3. **Security Tests** - اختبار الأمان
4. **Performance Tests** - اختبار الأداء

### تشغيل الاختبارات:

```bash
# جميع الاختبارات
php artisan test

# اختبارات محددة
php artisan test --filter=ProductTest

# اختبارات مع تغطية الكود
php artisan test --coverage
```

## 🐛 الإبلاغ عن الأخطاء

### معلومات مطلوبة:

1. **وصف الخطأ** - ما الذي حدث؟
2. **خطوات إعادة الإنتاج** - كيف يمكن إعادة إنتاج الخطأ؟
3. **السلوك المتوقع** - ما الذي كان يجب أن يحدث؟
4. **لقطات الشاشة** - إن أمكن
5. **معلومات البيئة** - نظام التشغيل، المتصفح، إلخ

### قالب الإبلاغ:

```markdown
## وصف الخطأ
وصف واضح ومختصر للخطأ.

## خطوات إعادة الإنتاج
1. اذهب إلى '...'
2. انقر على '...'
3. مرر إلى أسفل إلى '...'
4. شاهد الخطأ

## السلوك المتوقع
وصف واضح لما كان متوقعاً أن يحدث.

## لقطات الشاشة
إن أمكن، أضف لقطات شاشة لتوضيح المشكلة.

## معلومات البيئة
- نظام التشغيل: [مثل iOS]
- المتصفح: [مثل chrome, safari]
- الإصدار: [مثل 22]
```
