## 📖 نظرة عامة

متجر الأطفال الإلكتروني هو منصة تجارة إلكترونية متكاملة ومتطورة مصممة خصيصاً لبيع منتجات الأطفال. تم بناء المشروع باستخدام Laravel 11 مع التركيز على الأمان والأداء العالي وتجربة مستخدم متميزة.

### الهدف الرئيسي
توفير منصة تجارة إلكترونية سهلة الاستخدام وآمنة للتجار والعملاء في مجال منتجات الأطفال، مع دعم كامل للغة العربية وتجربة مستخدم متجاوبة عبر جميع الأجهزة.

## ✨ الميزات الرئيسية

### 1. واجهة المستخدم
- **تصميم عصري ومتجاوب**: يعمل بكفاءة على جميع الأجهزة (موبايل، تابلت، كمبيوتر)
- **دعم كامل للغة العربية**: واجهة مستخدم باللغة العربية مع اتجاه RTL
- **تجربة مستخدم سلسة**: تنقل سهل وبديهي بين الصفحات
- **تحميل سريع**: أداء محسن لسرعة التصفح

### 2. نظام البحث المتقدم
- **بحث ذكي**: يدعم البحث في أسماء المنتجات، الوصف، SKU
- **فلترة متعددة**: حسب الفئة، العلامة التجارية، اللون، الحجم، السعر
- **اقتراحات فورية**: عرض نتائج البحث أثناء الكتابة
- **ترتيب مرن**: حسب السعر، التاريخ، الاسم، المخزون

### 3. إدارة المنتجات
- **عرض المنتجات**: عرض مفصل مع صور عالية الجودة
- **مراجعات العملاء**: نظام تقييم ومراجعة شامل
- **منتجات مميزة**: عرض المنتجات المميزة على الصفحة الرئيسية
- **تتبع المخزون**: إدارة متقدمة للمخزون والتنبيهات

### 4. سلة التسوق
- **إدارة سهلة**: إضافة وتحديث وحذف المنتجات
- **كوبونات الخصم**: دعم تطبيق أكواد الخصم
- **حفظ السلة**: حفظ محتويات السلة للجلسات القادمة
- **تحديث فوري**: تحديث الأسعار والمجموع تلقائياً

### 5. إدارة الطلبات
- **تتبع الطلبات**: متابعة حالة الطلب في الوقت الفعلي
- **إشعارات**: تنبيهات عبر البريد الإلكتروني
- **تاريخ الطلبات**: عرض سجل كامل للطلبات السابقة
- **فاتورة PDF**: إمكانية تحميل فاتورة الطلب

## 🏗️ بنية النظام

### الطبقات الرئيسية

#### 1. طبقة العرض (Frontend)
- **القالب**: Blade Templates
- **التصميم**: Bootstrap 5
- **التفاعل**: JavaScript ES6
- **الأيقونات**: Font Awesome

#### 2. طبقة التحكم (Controllers)
- HomeController: إدارة الصفحة الرئيسية
- ShopController: إدارة المتجر والمنتجات
- CartController: إدارة سلة التسوق
- UserController: إدارة حساب المستخدم
- AdminController: إدارة لوحة التحكم

#### 3. طبقة الخدمات (Services)
- SearchService: إدارة البحث المتقدم
- RevenueAnalyticsService: تحليل الإيرادات
- PaymentService: معالجة المدفوعات

#### 4. طبقة النماذج (Models)
- Product: نموذج المنتج
- Category: نموذج الفئة
- Brand: نموذج العلامة التجارية
- Order: نموذج الطلب
- User: نموذج المستخدم

### قاعدة البيانات

#### الجداول الرئيسية
- users: بيانات المستخدمين
- products: بيانات المنتجات
- categories: الفئات
- brands: العلامات التجارية
- orders: الطلبات
- order_items: تفاصيل الطلبات
- cart: سلة التسوق
- reviews: المراجعات والتقييمات

## 📚 دليل المستخدم

### للعملاء

#### البحث عن المنتجات
1. استخدم شريط البحث في الصفحة الرئيسية
2. اكتب اسم المنتج أو الكلمة المفتاحية
3. استخدم الفلاتر لتضييق النتائج
4. اختر المنتج المناسب

#### إضافة منتج للسلة
1. افتح صفحة المنتج
2. اختر اللون والحجم (إن وجد)
3. حدد الكمية المطلوبة
4. اضغط على "أضف للسلة"

#### إتمام الشراء
1. افتح سلة التسوق
2. راجع المنتجات المختارة
3. اضغط على "إتمام الشراء"
4. أكمل بيانات الشحن والدفع
5. تأكيد الطلب

### للإدارة

#### إضافة منتج جديد
1. سجل الدخول للوحة التحكم
2. اذهب إلى "المنتجات"
3. اضغط على "إضافة منتج"
4. أدخل بيانات المنتج
5. أضف الصور
6. احفظ المنتج

#### إدارة الطلبات
1. اذهب إلى "الطلبات" في لوحة التحكم
2. اختر الطلب المطلوب
3. راجع تفاصيل الطلب
4. حدّث حالة الطلب
5. أضف معلومات التتبع (إن وجدت)
