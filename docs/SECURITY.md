## 📋 الأوامر الأمنية

### فحص الأمان
```bash
php artisan security:audit
php artisan security:audit --fix
```

### النسخ الاحتياطية
```bash
php artisan backup:secure
php artisan backup:secure --encrypt
```

### تحسين الأداء
```bash
php artisan optimize:performance
php artisan optimize:performance --force
```
