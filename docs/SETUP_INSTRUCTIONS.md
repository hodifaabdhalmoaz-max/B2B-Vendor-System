## 🔧 إعدادات إضافية

### تغيير إعدادات قاعدة البيانات
قم بتعديل ملف `.env`:
```
DB_DATABASE=kids_store
DB_USERNAME=root
DB_PASSWORD=
```

### تغيير إعدادات البريد الإلكتروني
```
MAIL_FROM_ADDRESS="noreply@kids-store.com"
MAIL_FROM_NAME="متجر الأطفال"
```
